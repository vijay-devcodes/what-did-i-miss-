Privacy & Security Policy

1. Ephemeral In-Memory Processing: Conversations are processed strictly in RAM and never written to permanent disk storage or persistent databases.
2. No Chat Logging: Our server does not write raw conversation text or sensitive tokens into server log files.
3. File Upload Safety: Uploaded chat files are parsed in memory, checked against size limits (2MB), and never executed.
4. Zero External Model Training: Your chat messages are not used to train machine learning models.
